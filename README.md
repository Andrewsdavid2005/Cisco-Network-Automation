# Cisco Network Automation

A beginner-friendly Cisco Network Automation project that combines **Cisco Packet Tracer, Python, and JSON** to demonstrate network configuration generation, IPv4 addressing, static routing, and network validation.

---

## Project Overview

This project demonstrates how network information can be stored in a structured **JSON** format and processed using **Python** to generate Cisco IOS configuration commands.

The generated configuration was then used with a simulated Cisco network in **Cisco Packet Tracer**.
